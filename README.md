This entry, "Gravity", is a deadpan one-star review of gravity. The complaint is one everyone has had: you drop your phone from waist height, gravity has the entire floor to land on, and it picks the corner of the screen. The program writes that single review line (123 characters, within the 1-160 limit) to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
